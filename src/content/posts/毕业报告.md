故事结束的很急促啊，突然收到学校的离校通知——校内有学生得新冠了，如今限制打开，校方的处理方案是得病的留在学校观察一段时间，没病的就赶紧离校——原先和朋友们约定的毕业活动也不了了之，没法子，也许这就是我们的命水，疫情真的彻底影响了我们的大学生涯。

在最后离开前，回忆一下这三年时光吧

## 回忆
大一时其实来的太匆忙了

因为疫情的缘故开学晚了很多

时间又紧张，课程也没有因为疫情减少，而且又还有军训

不过好在是那时的课程都属于比较简单的那种，那时我学起来都感觉不算难  

主要我也在来学校之前就已经接触过一些课程相关的知识了

感觉那时主要是偏玩乐一点吧，熟悉一下环境

不过我那时便发现学校和老师提供的知识可能不够应付将来的社会

所以我当时就觉得这样不行，光听课没用，得自己在网上找课程好好学才行



当时好像没有什么想加入的社团，因为感觉都没意思

不过，计算机协会在那里摆弄 AR 设备吸引到了我，所以就加入了

维修部，不过到现在毕业我好像也就帮人修过两三次电脑 hhhhh



说来可惜

这三年其实都没怎么出学校玩过

一是疫情管控，二是学校位置其实并不好

市内很多好玩的去处都普遍比较远

以至于如今回忆一阵

记忆都是在学校内的，实在可惜



大二和大三的回忆

虽然我能比较清晰的记得

但说实在的，很没意思

那段时间基本都是在学习学习，搞项目，准备比赛之类（可惜比赛也没搞成）

除去学习和必要的社交外

就是打游戏了

那段时间累，但也很满足，慢慢得进步的感觉

主要计算机的课程安排还不错

至少不会全周排满没一点空



## 朋友
说实话，在这大学三年里其实我的社交很简单啊

因为主要忙于学业和课外课程的缘故的

但还是有很多让我印象深刻以及怀念的人

比如我的沙雕舍友兼同学 —— 是的。我们宿舍其实不都是同一专业的学生

——说真的，这几年真的很多乐子都是从他身上来的



## 学业
| 课程名 | 主要来源 | 主要内容 |
| --- | --- | --- |
| Java 基础 + JavaEE | 校内专业课 + 网络公开课 | 是我们最核心的课程，也是我学了最久的一个课程，严格来说当时高三毕业之后我就开始学了，如今回头看真是难啊，目前看着就业前景还行，希望我能找到一份好工作吧 |
| Java SSM | 校内专业课 + 网络公开课 | 这个课程校内教的实在糟糕，很多我都是在网络自学的，难度很大主要很多概念不懂，甚至花了一个暑假都没有完全学明白 |
| Spring 框架 | 网络公开课 | 这个课程其实校内有教，但是真的超级糟糕，完全更没教似得，偏偏又这个课程嘴最重要，也很可惜没能完全学透——但其实目前也没有办法完全学透，必须通过实战才行 |
| MySQL 数据库 | 校内专业课 | 校内唯二最棒的专业课程，老师实在太有水平了，花了一学期学完非常有收获，我甚至认为比网上的课程还要好 |
| Linux 操作系统 | 网络公开课 | 校内其实也有教，但是我认为这是校内教的最糟糕的一门课，完全就是老师在上面向你演示这个东西怎么安装和怎么用，都不能称之为课程！ |
| HTML 基础 | 校内专业课 | 前端的大基础，说来搞笑当时不会用 div 和 css 直接用 table 标签 + 行内样式写了个 JOJO 主题网站 |
| CSS | 校内专业课 + 网络公开课 | 这个课程校内叫起来奇慢无比——主要为什么当时不和 HTML 课程一起学完呢，奇怪——但本身有很简单，所以我当时就去自学了 |
| JavaScript | 校内专业课 + 网络公开课 | 很长的一个课程，贯通了大一下学年 + 大二上学年，但如今想来其实效率有点太慢了，好在当时在网上自学了很多可以抽空学点别的 |
| Vue | 网络公开课 | 校内的完全就是一门注水课，但是这玩意又属于前端大热门框架，学了很值的 |
| 微信小程序 | 校内专业课 | 校内唯二最棒的专业课程，与我而言本来是完全不用学这玩意的，但是通过这门课我属于是看见的校内教学的天花板，任课老师的责任感和水平都是最高的那一档，学的最值的一门课 |
| UniAPP 小程序 | 网络公开课 | 为了比赛专门学的一门课，但很可惜疫情缘故，比赛没有举办 |
| 计算机网络 | 网络公开课 | 专科对比本科最可惜的一个地方，就是专科的 CS 专业没有和四大件相关的课程，只能自己自学 |
| Photoshop | 校内专业课  | 完全没学明白的一个课程（ |
| 色彩管理 | 校内专业课 | 学完终究还是个色盲 |
| 应用数学 | 校内选修课 | 学前：莫非是高等数学<br/>学后：居然是高中数学 |
