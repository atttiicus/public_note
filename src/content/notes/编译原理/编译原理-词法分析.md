# 词法分析

## 词法分析器

词法分析器读入源程序字符流，输出 token 序列，同时负责：

- 过滤空白、换行、制表符、注释
- 将 token 信息添加到符号表

词法分析器在逻辑上独立于语法分析，但通常与语法分析器在同一 Pass 中运行。

![](https://cdn.nlark.com/yuque/0/2026/png/26525545/1780379086562-0f3e395c-caaa-4f8a-bc84-3a2fa285db00.png)

### 基础概念

#### 词法单元（Token）

结构：`<词法单元名, 属性值（可选）>`

- **单元名**：表明词法单位的种类，是抽象符号。词法分析器通过各 token 的单元名即可确定词法单元序列的结构。
- **属性值**：可选，供语义分析之后的阶段使用。

#### 模式（Pattern）

描述一类词法单元的词素可能具有的形式。

#### 词素（Lexeme）

源程序中的字符序列。若某个词素与某个 token 的模式相匹配，则词法分析器将其识别为该 token 的一个实例。

### 词法分析器的功能

- **识别词法单元 token**
- 去除注释、空白、空行、制表符
- 将编译器生成的错误信息关联到源文件
- 可能进行**预处理**：识别宏（macro）并进行宏展开

#### Token 的类别

| 类别 | 示例 | 说明 |
|------|------|------|
| 关键字（Keyword） | `if`, `else`, `while`, `return` | 无属性值 |
| 标识符（Identifier） | 变量名等 | |
| 字面常数（Literal） | `12`, `true`, `1e+3` | |
| 运算符（Operator） | `+`, `-`, `*`, `/` | |
| 分界符（Delimiter） | 逗号、分号、冒号等 | |

### 词法分析器的输出

Token 的基本输出格式：`<类别编码, 词法单元自身的属性值>`

注意：**在词法分析过程中，有时需要任意长度的向前看（lookahead）。**

### 词法分析器的实现方式

- 实现为单独的一个扫描（pass）
- 作为语法分析或语义分析的子程序，每次调用 `getToken()` 获得一个 token

## 语言与正则表达式

**规约（Specification）**：用正则表达式描述处理词法单元时所用到的模式类型。

### 字母表（Alphabet）

**字母表**：符号的非空有穷集合。每种程序语言都有自己的字母表，例如：

- 机器语言：`{0, 1}`
- C 语言：ASCII 字符集

### 符号串（String / Word）

已知字母表 $\Sigma$，符号串的递归定义如下：

1. $\varepsilon$ 是 $\Sigma$ 上的一个符号串（空串）。
2. 若 $\alpha$ 是 $\Sigma$ 上的符号串，且 $a \in \Sigma$，则 $\alpha a$ 是 $\Sigma$ 上的符号串。
3. $\beta$ 是 $\Sigma$ 上的符号串，当且仅当它由规则 1 和/或 2 导出。

**定义**：由字母表中符号组成的任意有穷序列，称为该字母表上的**符号串**（也称**字**）。

#### 约定

- 靠前的小写字母表示**符号**：$a, b, c$
- 小写希腊字母或靠后的小写英文字母表示**符号串**：$\alpha, \beta, \gamma, x, y, z$
- $\varepsilon$ 表示**空串**
- 大写字母表示**符号串集合**：$A, B, C$

#### 相关概念

设 $x$ 是一个符号串：

- **前缀（prefix）**：移走 $x$ 尾部零个或多个连续符号所得。
- **后缀（suffix）**：移走 $x$ 头部零个或多个连续符号所得。
- **子串（substring）**：从 $x$ 中删去一个前缀和一个后缀所得。
- **真前缀 / 真后缀 / 真子串**：非空且不等于 $x$ 本身，即 $y \neq x$ 且 $y \neq \varepsilon$。
- **子序列（subsequence）**：从 $x$ 中删去零个或多个符号（不要求连续）所得。
- **逆转（reverse）**：记作 $x^R$，将 $x$ 中符号按相反次序写出。
- **长度（length）**：符号串中符号的数目，如 $|aab| = 3$，$|\varepsilon| = 0$。

#### 符号串的运算

1. **连接（concatenation）**：$xy$ 是把 $y$ 的符号写在 $x$ 之后得到的符号串。例：$x = ba,\ y = nana \Rightarrow xy = banana$。
2. **方幂（exponentiation）**：
   - $x^0 = \varepsilon$
   - $x^1 = x$
   - $x^n = x^{n-1}x$

### 语言（Language）

**语言**：某个给定字母表上任意可数的符号串集合。

**示例**：

- 空集 $\varnothing$
- 只含空串的集合 $\{\varepsilon\}$
- 所有符合规范的 C 语言标识符的集合
- 所有语法正确的 C 语言程序的集合

#### 语言的运算

设 $L$ 和 $M$ 是两个符号串集合：

1. **合并（union）**：$L \cup M = \{s \mid s \in L \text{ 或 } s \in M\}$
2. **连接（concatenation）**：$LM = \{st \mid s \in L \text{ 且 } t \in M\}$
3. **方幂（exponentiation）**：$L^0 = \{\varepsilon\}$，$L^n = L^{n-1}L$
4. **Kleene 闭包**：$L^* = \bigcup_{i \geq 0} L^i$
5. **正闭包**：$L^+ = \bigcup_{i \geq 1} L^i = L \cdot L^*$

#### 辨析：$\varnothing$ 与 $\{\varepsilon\}$

- **空集 $\varnothing$**：不含任何元素。对任意集合 $M$，有 $\varnothing M = M\varnothing = \varnothing$（空集与任何集合的笛卡尔积仍为空集）。
- **$\{\varepsilon\}$**：含一个元素，即空串。对任意集合 $M$，有 $\{\varepsilon\}M = M\{\varepsilon\} = M$（空串与任何字符串连接不改变该字符串）。

### 正则表达式与正则语言（Regular Expression）

字母表 $\Sigma$ 上的正则表达式及其对应的正则集合（正则语言），满足以下归纳定义：

1. $\varepsilon$ 是正则表达式，$L(\varepsilon) = \{\varepsilon\}$。
2. 若 $a \in \Sigma$，则 $a$ 是正则表达式，$L(a) = \{a\}$。
3. 归纳步骤：设 $r$ 和 $s$ 是 $\Sigma$ 上的正则表达式：
   - $(r)|(s)$：$L(r) \cup L(s)$（或）
   - $(r)(s)$：$L(r)L(s)$（连接）
   - $(r)^*$：$(L(r))^*$（Kleene 闭包）
   - $(r)$：$L(r)$（加括号不改变语言）

去掉冗余括号后，正则表达式表示的语言不变（注意运算优先级：闭包 > 连接 > 或）。

#### 正则表达式示例

$\Sigma = \{a, b\}$：

| 正则表达式 | 对应语言 |
|-----------|---------|
| $a \mid b$ | $\{a, b\}$ |
| $(a \mid b)(a \mid b)$ | $\{aa, ab, ba, bb\}$ |
| $a^*$ | $\{\varepsilon, a, aa, aaa, \ldots\}$ |
| $(a \mid b)^*$ | $\{\varepsilon, a, b, aa, ab, \ldots\}$（所有串） |
| $a^*b$ | $\{b, ab, aab, aaab, \ldots\}$ |

**C 语言标识符**（[可视化](https://regex-vis.com/?r=%5BA-Z_%5D%5BA-Za-z0-9_%5D*)）：

```plain
(A|B|...|Z|a|b|...|z|_)((A|B|...|Z|a|b|...|z|_|0|1|...|9))*
// [A-Z_][A-Za-z0-9_]*
```

**有符号整数**（[可视化](https://regex-vis.com/?r=%5B%2B-%5D%3F%5B0-9%5D%5B0-9%5D*)）：

```plain
(+|-|ε)(0|1|...|9)(0|1|...|9)*
// [+-]?[0-9][0-9]*
```

#### 正则表达式的代数性质

设 $e_1, e_2, e_3$ 均为某字母表上的正则表达式：

- **单位元**：$\varepsilon e = e\varepsilon = e$
- **交换律**：$e_1 \mid e_2 = e_2 \mid e_1$
- **结合律**：$e_1 \mid (e_2 \mid e_3) = (e_1 \mid e_2) \mid e_3$；$e_1(e_2 e_3) = (e_1 e_2)e_3$
- **分配律**：$e_1(e_2 \mid e_3) = e_1 e_2 \mid e_1 e_3$；$(e_1 \mid e_2)e_3 = e_1 e_3 \mid e_2 e_3$

此外：$r^* = (r\varepsilon)^*$；$r^{**} = r^*$；$(r \mid s)^* = (r^* s^*)^*$

#### 正则定义（Regular Definition）

正则定义是如下形式的定义序列：

$$D_1 \rightarrow R_1 \\ D_2 \rightarrow R_2 \\ \vdots \\ D_n \rightarrow R_n$$

其中 $D_1, \ldots, D_n$ 为正则表达式名字，$R_1, \ldots, R_n$ 为正则表达式。**限定**：$R_i$ 中只能出现字母表 $\Sigma$ 中的字符，以及前面已定义的名字 $D_1, \ldots, D_{i-1}$。

正则定义用于辅助描述程序语言的单词符号（相当于具名规则）。

#### 正则表达式的扩展形式

| 扩展符号 | 含义 | 等价写法 |
|---------|------|---------|
| $(r)+$ | 1 次或多次 | $r^+ = rr^* = r^*r$ |
| $r?$ | 0 次或 1 次 | $r \mid \varepsilon$ |
| $[abc]$ | 字符类 | $a \mid b \mid c$ |
| $[a\text{-}z]$ | 字符范围 | $a \mid b \mid \ldots \mid z$ |

建议参考 [RegexLearn](https://regexlearn.com/zh-cn/cheatsheet)。

#### 例题

**题目**：写出语言"所有相邻数字都不相同的非空数字串"的正则定义。

**解答**：

$$
\begin{aligned}
&\text{answer} \rightarrow (0 \mid \text{no\_0}\ \ 0)(\text{no\_0}\ \ 0)^*(\text{no\_0} \mid \varepsilon) \mid \text{no\_0} \\
&\text{no\_0} \rightarrow (1 \mid \text{no\_0-1}\ \ 1)(\text{no\_0-1}\ \ 1)^*(\text{no\_0-1} \mid \varepsilon) \mid \text{no\_0-1} \\
&\quad\vdots \\
&\text{no\_0-8} \rightarrow 9
\end{aligned}
$$

将上述正则定义逆序排列即为最终答案。

**说明**：

1. **顶层规则 `answer`**：可以是以 `0` 开头或以 `no_0` 开头的数字串。以 `0` 开头时，后面跟任意多个 `(no_0 0)` 组合，最后再跟一个 `no_0` 或为空 $\varepsilon$。
2. **子表达式 `no_0`**：表示不以 `0` 开头的数字串，定义方式与 `answer` 类似，但将 `0` 替换为 `1`。
3. **递归定义**：`no_0-1`、`no_0-2`……直到 `no_0-8` 依此类推，确保相邻数字始终不同；`no_0-8` 只能匹配 `9`。

## 状态转换图（Transition Diagram）

**状态（State）**：识别词素过程中可能出现的情况，是对已处理部分的总结。

- **接受状态（终止状态）**：表示找到词素。
- **带 * 的接受状态**：表示最后读入的符号不属于该词素。
- **开始状态（初始状态）**：用"开始/Start"边标记。

**边（Edge）**：从一个状态指向另一个状态，标号为一个或多个符号。当前状态为 $s$，输入符号为 $a$，则沿标号 $a$ 的边转移：$s \xrightarrow{a} s'$。

### 词法单元的自动识别

**基本目标**：判断串 $s$ 是否属于正则表达式 $R$ 表示的语言，即 $s \in L(R)$。

### 词法自动识别过程

1. 为每类词法单元写出正则表达式 $R_i$。
2. 构造合并的正则表达式：$R = R_1 \mid R_2 \mid \ldots \mid R_k$。
3. 对输入 $x_1 x_2 \ldots x_n$，对 $1 \leq i \leq n$，检查 $x_1 \ldots x_i \in L(R)$。
4. 若匹配成功，找到 $j$ 使 $x_1 \ldots x_i \in L(R_j)$。
5. 将 $x_1 \ldots x_i$ 从输入中移走，回到步骤 3。

### 匹配中需要解决的问题

1. **确定匹配长度**：可能有多个前缀匹配，选择**最长匹配**。
2. **选择正则表达式**：多个正则表达式同时匹配时，**优先匹配排在前面的**。
3. **无法匹配**：构造 ERROR 正则表达式，放在表末尾用于报错。

## Lex

**Lex** 是一种词法分析程序自动构造工具，通常与 Yacc 配合使用，生成编译器前端。

**实现原理**：根据正则表达式自动生成词法分析程序，利用正则表达式与 DFA 的等价性。

**转换流程**：正则表达式 $\Rightarrow$ NFA $\Rightarrow$ DFA $\Rightarrow$ 最小化 DFA

### 用 Lex 建立词法分析程序的过程

![](https://cdn.nlark.com/yuque/0/2026/png/26525545/1780379128701-66e1c981-7ded-47ad-92a8-db3a634318b5.png)

### 词法分析器的工作方式

- Lex 生成的词法分析器以函数形式被调用。
- 每次调用时读取输入符号。
- 发现最长匹配的输入前缀时，执行相应动作：
  - 若动作中有返回，则返回控制权；
  - 若不返回，则继续寻找下一个词素。

### Lex 源程序结构

Lex 源程序由三部分组成，各部分用 `%%` 分隔：

#### 声明部分

包括变量、C 语言常量和正则定义式。

#### 转换规则及动作

形式：`p_i { 动作 i }`。识别到某类单词时执行对应动作，动作用 C 语言编写。

#### 辅助子程序

执行动作所需的 C 语言函数，可单独编译。

**冲突解决**：优先按规则顺序匹配，排在前面的规则优先。

### Lex 程序示例

```plain
%{
/* 定义常量 */
LT, LE, EQ, NE, GT, GE, IF, THEN, ELSE, ID, NUMBER, RELOP
%}

/* 正则定义 */
delim       [\t\n]
ws          {delim}+
Letter      [A-Za-z]
digit       [0-9]
id          {Letter}({Letter}|{digit})*
Number      {digit}+(\.{digit}+)?(E[+-]?{digit}+)?

%%

{ws}        {/* 不返回 */}
if          {return(IF);}
then        {return(THEN);}
else        {return(ELSE);}
{id}        {yylval = (int) installID(); return(ID);}
{number}    {yylval = (int) installNum(); return(NUMBER);}
"<"         {yylval = LT; return(RELOP);}
"<="        {yylval = LE; return(RELOP);}
"=="        {yylval = EQ; return(RELOP);}
"!="        {yylval = NE; return(RELOP);}
">"         {yylval = GT; return(RELOP);}
">="        {yylval = GE; return(RELOP);}

%%

int installID() {/* 添加符号表指向 yytext */}
int installNum() {/* 添加数字常量到表格 */}
```

`yylval` 是 Lex 提供的全局变量，用于返回词法单元的属性值。

## 有限自动机（Finite Automata）

有限自动机是词法分析器生成工具（如 Lex）的核心技术：

$$\text{正则表达式} \rightarrow \text{有限自动机} \rightarrow \text{词法分析程序}$$

**识别功能**：有限自动机与状态转换图类似，对每个输入串只能回答"接受"或"拒绝"。

**分类**：

- **确定的有限自动机（DFA，Deterministic Finite Automaton）**
- **不确定的有限自动机（NFA，Nondeterministic Finite Automaton）**

### 确定的有限自动机（DFA）

**定义**：DFA $M$ 是一个五元组 $M = (\Sigma, Q, q_0, F, \delta)$，其中：

1. $\Sigma$：有限输入字母表。
2. $Q$：有限状态集合。
3. $q_0 \in Q$：初始状态。
4. $F \subseteq Q$：终止（接受）状态集合。
5. $\delta: Q \times \Sigma \to Q$：**单值**转换函数，$\delta(q, a) = q'$ 表示在状态 $q$ 下读入符号 $a$ 后转移到状态 $q'$。

#### DFA 接受的语言

DFA 接受字符串 $w$ 当且仅当存在从初始状态到某接受状态的路径，路径上符号序列恰好为 $w$。形式化定义：

- $\delta(q, \varepsilon) = q$
- $\delta(q, wa) = \delta(\delta(q, w), a)$
- $L(M) = \{w \mid w \in \Sigma^*,\ \exists q \in F,\ \delta(q_0, w) = q\}$

#### 表示形式

- 转移矩阵
- 状态转换图

![](https://cdn.nlark.com/yuque/0/2026/png/26525545/1780379160510-57eb8f25-81a5-493d-be6f-d736b5505439.png)

#### 举例：识别能被 5 整除的二进制数

字母表 $\Sigma = \{0, 1\}$，DFA 的转换规则为：

$$q \xrightarrow{a} q': \quad q' = (2 \times q + a) \bmod 5$$

![](https://cdn.nlark.com/yuque/0/2026/png/26525545/1780379182727-3af733f0-7f51-4aec-aced-20c00c31e0c7.png)

对应正则表达式：

```plain
(0|1(10)*(0|11)(01*01|01*00(10)*(0|11))*1)*
```

### 不确定的有限自动机（NFA）

**定义**：NFA $M$ 是一个五元组 $M = (\Sigma, Q, q_0, F, \delta)$，各分量含义与 DFA 相同，区别在于转换函数：

$$\delta: Q \times (\Sigma \cup \{\varepsilon\}) \to 2^Q$$

即 $\delta$ 是多值映射，允许 $\varepsilon$ 转换，且同一状态对同一输入符号可以转移到多个状态（$2^Q$ 表示 $Q$ 的幂集）。

#### NFA 接受的语言

若 NFA 中存在从初始状态到某接受状态的路径，且路径上符号序列为 $w$，则 NFA 接受 $w$，记作 $w \in L(M)$。

**说明**：

- 同一字符串在 NFA 中可能对应多条路径，只要有一条路径到达接受状态即可接受。
- 若某状态对输入符号 $a$ 没有可用的转移，则该路径无法继续（该路径拒绝，但不影响其他路径）。
- **DFA 是 NFA 的特例**，两者的表达能力等价。

## 从 NFA 构造 DFA（子集构造法）

### $\varepsilon$-闭包

**定义**：从状态集合 $S$ 中任意状态出发，仅沿 $\varepsilon$ 弧可达的所有状态（含 $S$ 自身）构成 $S$ 的 $\varepsilon$-闭包，记为 $\varepsilon\text{-closure}(S)$：

$$T = S \cup \left(\bigcup_{t \in T} \text{edge}(t, \varepsilon)\right)$$

其中 $\text{edge}(t, a)$ 是从状态 $t$ 出发仅沿 $a$ 弧到达的状态集合。

### DFA $M'$ 的构造

- $M'$ 中每个状态对应 NFA $M$ 的一个状态集合。
- $M'$ 的初始状态：$d_0 = \varepsilon\text{-closure}(\{t_0\})$，其中 $t_0$ 是 $M$ 的初始状态。
- **$M'$ 的终止状态**：凡包含 $M$ 中任意终止状态的状态集合，均为 $M'$ 的终止状态。

### DFA $M'$ 的转移函数

$$\text{DFAedge}(d, a) = \varepsilon\text{-closure}\left(\bigcup_{t \in d} \text{edge}(t, a)\right)$$

其中 $d$ 是 NFA 的状态集合，$a \in \Sigma$。

## DFA 的最小化

给定 DFA $M = (\Sigma, Q, q_0, F, \delta)$，寻找状态数最少的等价 DFA $M'$，使 $L(M') = L(M)$。

### 等价状态

若对所有 $w \in \Sigma^*$，$\delta(p, w) \in F$ 当且仅当 $\delta(q, w) \in F$，则称状态 $p$ 和 $q$ **等价**；否则称它们**可区别**。

等价的状态可以合并为一个状态，而不影响 DFA 接受的语言。

### 等价状态的判别条件

两个状态 $p$ 和 $q$ 等价，需同时满足：

- **一致性条件**：$p$ 和 $q$ 必须同时为接受状态，或同时为非接受状态。
- **蔓延性条件**：对所有 $a \in \Sigma$，若 $\delta(p, a) = r$，$\delta(q, a) = s$，则 $r$ 和 $s$ 也必须等价。反之，若 $r$ 和 $s$ 不等价，则 $p$ 和 $q$ 不等价。

### 等价类划分算法

1. 将所有状态初始划分为两组：接受状态组和非接受状态组。
2. 对任意输入符号 $a$，检查每组内各状态在 $a$ 下的转移目标。若同组中的状态转移到不同的组，则按转移目标所在组对该组进行分割。
3. 重复第 2 步，直到每组内所有状态对所有输入符号的转移均落在同一组中。

> 本质上是一个不断细化的分割过程：初始分割粗糙，每轮迭代根据转移目标的差异进一步分裂，直至稳定。

## 从正则表达式构造有限自动机（Thompson 构造法）

**定理**：对字母表 $\Sigma$ 上任意正则表达式 $r$，存在 NFA $M$ 使得 $L(M) = L(r)$，且 $M$ 的终态唯一且无出边。

**证明思路**：对正则表达式 $r$ 的运算符数目作归纳。

**基础情形**（零个运算符）：$r = \varepsilon$，$r = \varnothing$，或 $r = a \in \Sigma$，对应的 NFA 分别为：

![](https://cdn.nlark.com/yuque/0/2026/png/26525545/1780379276521-a892d8e8-fccc-41eb-96df-169a3e562b8c.png)

**归纳步骤**：设结论对少于 $i$（$i \geq 1$）个运算符的正则表达式成立。当 $r$ 有 $i$ 个运算符时，分三种情况构造：

- **$r = r_1 \mid r_2$**

![](https://cdn.nlark.com/yuque/0/2026/png/26525545/1780379300723-bb473cc9-1197-4549-adef-e7cc7688fa50.png)

- **$r = r_1 r_2$**

![](https://cdn.nlark.com/yuque/0/2026/png/26525545/1780379318257-4eeafc47-bfb5-4d8f-ba7b-3088dfa56693.png)

- **$r = r_1^*$**

![](https://cdn.nlark.com/yuque/0/2026/png/26525545/1780379330470-94530215-e9e7-485e-8bd4-f58b758e603f.png)

由 $M_1 = (\Sigma_1, Q_1, q_1, F_1, \delta_1)$ 和 $M_2 = (\Sigma_2, Q_2, q_2, F_2, \delta_2)$ 构造 $M$，使 $L(M) = L(r)$，构造方式如图所示。由此可对任意正则表达式归纳地构造出对应的 NFA。

### Thompson 构造得到的 NFA 的特性

- 状态数量不超过正则表达式中运算符与运算分量总数的两倍（每步最多引入两个新状态）。
- 有且只有一个开始状态和一个接受状态。
- 除接受状态外，每个状态要么有一条标号不为 $\varepsilon$ 的出边，要么有两条标号为 $\varepsilon$ 的出边。

## 多模式 NFA 的合并与驱动词法分析器

### NFA 合并方法

将多个正则式对应的 NFA 合并为一个大 NFA：

1. **引入新开始状态** $s_0$，从 $s_0$ 向各原 NFA 的开始状态各引一条 $\varepsilon$ 弧。
2. **合并后语言**：新 NFA 接受的语言是各原 NFA 语言的并集。
3. **保留各接受状态**：不同接受状态代表不同的模式，用于后续的模式识别。

![](https://cdn.nlark.com/yuque/0/2026/png/26525545/1780379350176-2a627854-366b-4369-8381-e8969b61ca4e.png)

### NFA 到 DFA 的转换与冲突处理

1. **确定化**：对合并后的 NFA 进行子集构造，得到 DFA；可进一步对 DFA 进行最小化。
2. **接受状态映射**：DFA 的一个接受状态对应 NFA 状态的某个集合，该集合中**至少包含一个 NFA 接受状态**。若集合中包含多个对应不同模式的 NFA 接受状态，则当前输入前缀对多个模式均匹配，存在冲突。
3. **冲突解决**：选取排序最靠前的模式作为该 DFA 接受状态的输出。

### 词法分析器的运行方式

1. **模拟 DFA**，不断读入输入字符，直到某时刻没有可用后继为止（不是等到达接受状态才停止）。
2. **向前回溯**，找到最后一个经过的接受状态，执行对应动作：
   - 若能找到接受状态，执行相应动作并将输入指针回退到该状态对应的位置；
   - 若找不到，报告词法错误。
