# 堆

<u>堆（heap）</u>是一种满足特定条件的完全二叉树，主要分为两种类型：

- <u>小顶堆（min heap）</u>：任意节点的值 $\leq$ 其子节点的值。
- <u>大顶堆（max heap）</u>：任意节点的值 $\geq$ 其子节点的值。

![](https://cdn.nlark.com/yuque/0/2025/png/26525545/1767003289572-8b620ebf-dda9-452e-b721-809fd99e100d.png)

堆作为完全二叉树的一个特例，具有以下特性：

- 最底层节点靠左填充，其他层节点都被填满。
- 二叉树的根节点称为"堆顶"，底层最靠右的节点称为"堆底"。
- 大顶堆的堆顶元素值最大，小顶堆的堆顶元素值最小。

## 堆的常用操作

许多编程语言提供的是<u>优先队列（priority queue）</u>——一种以优先级排序的抽象数据结构。**堆通常用于实现优先队列，大顶堆相当于元素按从大到小顺序出队的优先队列**。从使用角度来看，两者可视为等价的数据结构，本文统一称作"堆"。

堆的常用操作如下表所示（方法名因编程语言而异）：

| 方法名        | 描述                                             | 时间复杂度    |
| ------------- | ------------------------------------------------ | ------------- |
| `push()`      | 元素入堆                                         | $O(\log n)$   |
| `pop()`       | 堆顶元素出堆                                     | $O(\log n)$   |
| `peek()`      | 访问堆顶元素（大/小顶堆分别为最大/最小值）       | $O(1)$        |
| `size()`      | 获取堆的元素数量                                 | $O(1)$        |
| `isEmpty()`   | 判断堆是否为空                                   | $O(1)$        |

在实际应用中，可直接使用编程语言提供的堆类（或优先队列类）。类似排序中"从小到大"与"从大到小"的切换，可通过设置 `flag` 或修改 `Comparator` 实现小顶堆与大顶堆之间的转换：

```python
# 初始化小顶堆
min_heap, flag = [], 1
# 初始化大顶堆
max_heap, flag = [], -1

# Python 的 heapq 模块默认实现小顶堆
# 考虑将"元素取负"后再入堆，这样就可以将大小关系颠倒，从而实现大顶堆
# 在本示例中，flag = 1 时对应小顶堆，flag = -1 时对应大顶堆

# 元素入堆
heapq.heappush(max_heap, flag * 1)
heapq.heappush(max_heap, flag * 3)
heapq.heappush(max_heap, flag * 2)
heapq.heappush(max_heap, flag * 5)
heapq.heappush(max_heap, flag * 4)

# 获取堆顶元素
peek: int = flag * max_heap[0] # 5

# 堆顶元素出堆
# 出堆元素会形成一个从大到小的序列
val = flag * heapq.heappop(max_heap) # 5
val = flag * heapq.heappop(max_heap) # 4
val = flag * heapq.heappop(max_heap) # 3
val = flag * heapq.heappop(max_heap) # 2
val = flag * heapq.heappop(max_heap) # 1

# 获取堆大小
size: int = len(max_heap)

# 判断堆是否为空
is_empty: bool = not max_heap

# 输入列表并建堆
min_heap: list[int] = [1, 3, 2, 5, 4]
heapq.heapify(min_heap)
```

## 堆的实现

以下实现的是大顶堆。若要转换为小顶堆，只需将所有大小逻辑判断取反（例如将 $\geq$ 替换为 $\leq$）。

### 存储与表示

完全二叉树非常适合用数组表示，堆也不例外。**数组中的元素代表节点值，索引代表节点在二叉树中的位置，节点间的父子关系通过索引映射公式实现**。

如下图所示，给定索引 $i$：

- 左子节点索引为 $2i + 1$
- 右子节点索引为 $2i + 2$
- 父节点索引为 $(i - 1) / 2$（向下整除）

索引越界时，表示该节点不存在。

![](https://cdn.nlark.com/yuque/0/2025/png/26525545/1767003426145-3506b81d-716d-4833-b24b-b3d2bea9e407.png)

将上述映射公式封装为函数如下：

```python
def left(self, i: int) -> int:
    """获取左子节点的索引"""
    return 2 * i + 1

def right(self, i: int) -> int:
    """获取右子节点的索引"""
    return 2 * i + 2

def parent(self, i: int) -> int:
    """获取父节点的索引"""
    return (i - 1) // 2  # 向下整除
```

### 访问堆顶元素

堆顶元素即二叉树的根节点，对应数组的首个元素：

```python
def peek(self) -> int:
    """访问堆顶元素"""
    return self.max_heap[0]
```

## 堆的常见应用

- **优先队列**：堆是实现优先队列的首选数据结构，入队和出队操作时间复杂度均为 $O(\log n)$，建堆操作为 $O(n)$，整体非常高效。
- **堆排序**：利用堆构建有序序列——先建堆，再不断执行出堆操作即可得到有序数据。更优雅的实现方式详见"堆排序"章节。
- **获取最大的 $k$ 个元素**：经典算法问题，典型应用如微博热搜前 10、销量前 10 的商品等。

# 建堆操作

在某些情况下，需要用一个列表的所有元素来构建一个堆，这一过程称为"建堆操作"。

## 方法一：借助入堆操作

创建空堆后，遍历列表，对每个元素依次执行入堆操作：将元素添加至堆的尾部，再对该元素执行"从底至顶"堆化。

节点从顶到底依次加入，堆是"自上而下"构建的。设元素数量为 $n$，每次入堆使用 $O(\log n)$ 时间，因此该方法的时间复杂度为 $O(n \log n)$。

## 方法二：通过遍历堆化实现

此方法更为高效，分两步执行：

1. 将列表所有元素原封不动地填入堆中（此时堆性质尚未满足）。
2. 倒序遍历所有非叶节点，对每个节点执行"从顶至底"堆化。

**每堆化一个节点后，以该节点为根的子树便形成合法子堆**。由于是倒序遍历，堆是"自下而上"构建的，可保证处理当前节点时其所有子树已经是合法子堆。

叶节点天然是合法子堆，无须堆化。最后一个非叶节点是最后一个节点的父节点，从它开始倒序遍历：

```python
def __init__(self, nums: list[int]):
    """构造方法，根据输入列表建堆"""
    # 将列表元素原封不动添加进堆
    self.max_heap = nums
    # 堆化除叶节点以外的其他所有节点
    for i in range(self.parent(self.size() - 1), -1, -1):
        self.sift_down(i)
```

## 复杂度分析

直觉上，方法二每个节点最多堆化到叶节点，最大迭代次数为树高 $\log n$，需要堆化的节点数量为 $(n-1)/2$，相乘得 $O(n \log n)$。**但这一估算过于保守，没有考虑到底层节点数量远多于顶层节点的特性**。

以下进行更精确的推导。假设节点数量为 $n$、高度为 $h$ 的完美二叉树（不影响结论的正确性）。

![](https://cdn.nlark.com/yuque/0/2025/png/26525545/1767003705840-9997b1d6-9f99-43f0-b40f-bf55c0a7b0ba.png)

节点"从顶至底堆化"的最大迭代次数等于该节点到叶节点的距离，即节点高度。对各层"节点数量 $\times$ 节点高度"求和，得到所有节点的堆化迭代次数总和：

$$
T(h) = 2^0h + 2^1(h-1) + 2^2(h-2) + \dots + 2^{h-1} \times 1
$$

将 $T(h)$ 乘以 $2$：

$$
\begin{aligned}
T(h) &= 2^0h + 2^1(h-1) + 2^2(h-2) + \dots + 2^{h-1}\times1 \\
2T(h) &= 2^1h + 2^2(h-1) + 2^3(h-2) + \dots + 2^{h}\times1
\end{aligned}
$$

错位相减，$2T(h) - T(h)$，得：

$$
T(h) = -2^0h + 2^1 + 2^2 + \dots + 2^{h-1} + 2^h
$$

$T(h)$ 右侧为等比数列，代入求和公式：

$$
\begin{aligned}
T(h) &= 2\frac{1 - 2^h}{1 - 2} - h \\
&= 2^{h+1} - h - 2 \\
&= O(2^h)
\end{aligned}
$$

高度为 $h$ 的完美二叉树节点数量为 $n = 2^{h+1} - 1$，因此 $O(2^h) = O(n)$。

**结论：通过遍历堆化实现的建堆操作，时间复杂度为 $O(n)$，显著优于逐个入堆的 $O(n \log n)$。**
