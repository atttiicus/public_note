# 二叉树

<u>二叉树（binary tree）</u>是一种非线性数据结构，体现"祖先"与"后代"之间的派生关系，以及"一分为二"的分治逻辑。与链表类似，二叉树的基本单元是节点，每个节点包含值、左子节点引用和右子节点引用。

```typescript
/* 二叉树节点类 */
class TreeNode {
    val: number
    left: TreeNode | null
    right: TreeNode | null

    constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
        this.val = val === undefined ? 0 : val // 节点值
        this.left = left === undefined ? null : left // 左子节点引用
        this.right = right === undefined ? null : right // 右子节点引用
    }
}
```

每个节点拥有两个引用，分别指向<u>左子节点（left-child node）</u>和<u>右子节点（right-child node）</u>，该节点称为这两个子节点的<u>父节点（parent node）</u>。以某节点为根，其左子节点及以下所有节点构成该节点的<u>左子树（left subtree）</u>，同理可得<u>右子树（right subtree）</u>。

**在二叉树中，除叶节点外，其余所有节点都包含子节点和非空子树。** 以"节点 2"为父节点为例，其左子节点为"节点 4"，右子节点为"节点 5"；左子树为"节点 4 及其以下节点构成的树"，右子树为"节点 5 及其以下节点构成的树"。

## 常见术语

- <u>根节点（root node）</u>：位于二叉树顶层、没有父节点的节点。
- <u>叶节点（leaf node）</u>：没有子节点的节点，其左右指针均指向 `null`。
- <u>边（edge）</u>：连接两个节点的线段，即节点间的引用（指针）。
- 节点的<u>层（level）</u>：从顶至底递增，根节点所在层为 1。
- 节点的<u>度（degree）</u>：该节点拥有的子节点数量，在二叉树中取值为 0、1 或 2。
- 二叉树的<u>高度（height）</u>：从根节点到最远叶节点所经过的边的数量。
- 节点的<u>深度（depth）</u>：从根节点到该节点所经过的边的数量。
- 节点的<u>高度（height）</u>：从该节点到其最远叶节点所经过的边的数量。

:::warning
"高度"与"深度"通常定义为经过的**边**的数量。部分题目或教材将其定义为经过的**节点**数量，此时高度和深度均需加 1。
:::
