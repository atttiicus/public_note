## 定义（建议）

定义AI的角色身份（如：资深前端架构师）

- 定义AI的能力（如：精通性能优化、精通 React 底层原理等）

## 背景 （必须）

描述你当前遇到的问题是怎么样的（如：我这里有一个长列表渲染组件，目前在渲染 1000 条数据时会出现明显的掉帧。）

## 任务 （必须）

描述你需要AI做什么 （如：请帮我优化或者重构这段代码。）

## 约束 （建议）

对AI进行约束（不要引入新的第三方库，仅使用原生 React Hooks 和 CSS 优化；代码需要包含详细的性能优化思路注释。）

## 步骤 （可选）

描述你想要AI执行的步骤（如：扫描一下相关代码，找出性能瓶颈，然后再给出重构后的代码，最后进行完整测试）
