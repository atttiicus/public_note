## 问题简述

### 字体替换：中文 → Noto Sans SC，英文 → JetBrains Mono
- **策略**：利用 CSS font-family 回退机制，`'JetBrains Mono Variable', 'Noto Sans SC Variable', monospace`，拉丁字符命中 JetBrains Mono，CJK 字符回退到 Noto Sans SC。
- **实施**：
  1. 安装 `@fontsource-variable/noto-sans-sc`
  2. BaseLayout.astro：移除 Lora + Playfair Display，加载 `noto-sans-sc/wght.css` + `jetbrains-mono/wght.css`（仅 wght 轴，不加载 italic 以减小体积）
  3. styles.css：统一四个变量（`--font-display`/`--font-serif`/`--font-sans`/`--font-mono`）为相同栈，body 默认 `font-weight: 400`
  4. 修复 pre-existing bug：CSS 中 JetBrains Mono 引用名缺 ` Variable` 后缀导致字体从未生效
- **结果**：构建 70 页零错误零警告，JetBrains Mono + Noto Sans SC 字体文件正确打包到 dist。
- **附加修复**：timeline.astro 第 228 行 CSS 语法错误（`align-items: flex-start;tl-date` → `align-items: flex-start;`）
