## 问题简述

### 报错1 & 2：GSAP MIME type + React useState null
- **根本原因**：Vite 依赖预构建缓存（`node_modules/.vite`）中缺失 GSAP，导致模块加载返回空 MIME 类型，连锁引发 React 初始化失败（`useState` dispatcher 为 null）。
- **处理方案**：清除 `node_modules/.vite` 缓存目录，重启 dev server 触发 Vite 重新预构建依赖。
- **处理结果**：清除缓存后 dev server 正常运行，首页和时间线页面均返回 HTTP 200，无运行时错误。

### 时间线样式错乱
- **根本原因**：原 CSS 在 flex 容器内大量使用 `position: absolute` 定位时间标记点和日期标签，与 flex 布局产生冲突，导致定位不可靠。
- **处理方案**：重写为纯 flex 三列布局（`[spacer 1fr] [marker auto] [cards 1fr]`），中心线使用 `.timeline::before` 伪元素，dot + 日期位于固定宽度的 marker 列内，数学上保证 marker 列中心恰好在容器 50% 处与中心线重合。
- **处理结果**：构建成功，70 页，时间线页面正确展示 24 篇笔记 / 4 个月份，左右交替布局正常。

### 补充：子目录笔记缺失 date 字段
- 为 `src/content/notes/**/` 下 16 篇笔记按 git 创建日期补充了 `date` 元数据。
